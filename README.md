# FF JODI — Starter Project

A mobile-first prototype for the FF JODI gun-combination checker.

## What is included
- Clean home page inspired by the supplied reference image
- BR / CS / High Damage / Pro / Range / Rush category cards
- Gun-only Jodi cards
- Gun + Character preview cards
- Gun selector and Jodi builder
- 5-level rating: Excellent / Great / Good / Average / Weak
- Estimated range/rush metrics
- Save Jodi on the current device with localStorage
- Simple profile UI
- Share result
- Responsive mobile layout

## Important
This is a front-end prototype. The gun list and score rules are sample data and must be replaced with verified, current game data before public launch.

The login in this prototype is local-device demo login, not real Google authentication.

## Run
Open `index.html` in a browser.
